Що змінилося у виводі git status після git add?
Файл перемістився зі списку невідстежуваних або змінених файлів до списку підготовлених до commit.



Що показує git diff?
Показує різницю між попередньою версією файлу та поточними змінами.



Чим відрізняється git switch main від git merge?
switch перемикає між гілками, а merge об'єднує зміни однієї гілки з іншою.



Чому виник конфлікт і як ти його розв'язав?
Конфлікт виник через зміну одного рядка в різних гілках. Я вручну об'єднав обидва варіанти заголовка та видалив службові маркери конфлікту.
